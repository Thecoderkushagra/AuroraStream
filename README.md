# Fnt-Aurora

React + Vite frontend for the [Aurora Stream](https://github.com/Thecoderkushagra/AuroraStream) Spring Boot backend project.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
